# Valheim Heraldry Mod

Write a heraldic blazon ("Azure, a bend or") and see it painted on banners, shields and tabards. Every player renders the arms from the text, so nothing image-like is sent between players.

**Work in progress. Nothing playable yet.**

## Requirements
- Must be installed on the server and on every client, with the same version.
